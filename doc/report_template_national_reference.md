# 全国版居民留言报告模板参考

本文档用于保存当前 Demo 曾经参考的“全国版”报告框架，方便以后扩展到多省、多市、多平台时复用。全国版模板的特点是覆盖面广、层级多、强调横向比较，但直接套到苏州单城 Demo 上会显得空泛，因此需要做苏州适配。

## 适用场景

- 已接入多个省份、多个城市或多个留言平台。
- 需要比较区域差异、跨省共性问题、区域治理能力差异。
- 需要生成面向省级、国家级或综合研究部门的宏观分析报告。

## 推荐章节

### 一、总体概况

说明样本来源、时间范围、地区覆盖、留言总量、回复总量、回复率、平均回复耗时等基础指标。

全国版应突出“区域分布”和“平台覆盖”，例如东中西部、城市群、省份排名、重点城市等。

### 二、区域分布与问题结构

从省份、城市、区县等维度展示诉求分布，分析留言高发地区、问题类型集中地区、治理压力较大的区域。

可配图：

- 全国或省域热力图
- 省份留言量排名
- 问题类型堆叠图
- 区域回复效率对比图

### 三、高频问题与典型议题

按主题归纳群众集中反映的问题，例如住房保障、交通出行、生态环境、教育医疗、市场监管、基层治理等。

全国版应强调共性问题和区域差异，而不是过度展开某一城市的单案细节。

### 四、办理回复与政府回应

分析回复部门、回复效率、答复质量、协同办理情况。重点观察是否存在部门职责交叉、回复模板化、重复投诉等治理信号。

### 五、趋势研判与风险提示

结合月度、季度、年度变化，识别阶段性热点和潜在风险。全国版可进一步比较节假日、季节性、政策节点、区域政策差异对诉求变化的影响。

### 六、治理建议

提出分层分类建议，例如国家层面制度完善、省级统筹协调、市县具体整改、平台数据治理等。

## 不适合直接用于苏州 Demo 的地方

- 全国版会自然出现“样本覆盖不足”“城市数量有限”“区域代表性有限”等说明，这些话适合研究方法章节，不适合作为苏州专报主体表达。
- 全国版强调跨区域比较，而苏州 Demo 当前更需要把苏州本地问题讲深、讲具体、讲出可执行建议。
- 全国版如果缺少多城市数据，容易生成“看似宏观、实际空泛”的内容。
- 全国版地图和区域排名依赖多地区数据，苏州 Demo 应改为“苏州城市诉求画像”和“重点议题专题分析”。

## 扩展到全国时的复用方式

当前苏州 Demo 可以保留全国版章节思想，但应把章节粒度改成“城市治理专题”。未来接入更多城市后，再恢复全国版中的区域对比、城市排名、跨区域差异和多层级治理建议。
